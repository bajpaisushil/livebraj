# Deity photographs

Drop image files here and reference them from `client/src/content/deities.js`.

- **JPG or PNG**, roughly square, 512–1024 px on a side is plenty.
- The Deity should fill the frame, shot straight on, cropped to the altar.
- Name them after the landmark: `iskcon-krishna-balaram-centre.jpg`.

Only add an image you have the right to distribute: one you took, one under a
licence that permits it, or one the temple has given you permission to use.
Record the source and the licence in the manifest entry — that is not
bureaucracy, it is the thing that lets this ship.

A landmark with no image falls back to the carved geometry already in the world.
